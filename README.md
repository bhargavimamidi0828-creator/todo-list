# ✅ To-Do List Web App

A simple and interactive To-Do List web application that helps users manage daily tasks.  
Users can add tasks, mark them as completed, and remove tasks easily.

---

## 📌 Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Simple and clean user interface

---

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript

---

## 🚀 How to Use
1. Open the website.
2. Enter a task in the input box.
3. Click **Add** to add the task.
4. Click on a task to mark it as completed.
5. Click the delete button to remove the task.
